About AquaSense

A smart water distribution platform designed to improve irrigation reliability using ultrasonic tank sensing, flow metering, long-range LoRa nodes, and MQTT telemetry.

Water Monitoring

Monitor flow rate, cumulative volume, soil moisture, temperature, humidity, and tank levels in real time.

LoRa Multi-Master

Each master controller coordinates its local LoRa customer nodes and reports independently over MQTT.

Manual Control

Valves and the main pump are switched manually from this dashboard. Nothing is switched automatically, except safety cut-offs in the firmware (maximum valve open time, maximum pump run time).

Security Hardening

Strict Content Security Policy, validated master and node identifiers, safe DOM rendering, and stale-retained telemetry detection.
