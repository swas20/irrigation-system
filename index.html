About AQUASENSE

A smart irrigation system and monitoring platform designed to improve water management using automation, sensors, LoRa communication and cloud connectivity.

🌊 Water Monitoring

Monitor flow rate, total water consumption and water distribution in real time.

📡 LoRa Communication

Customer nodes communicate with the master controller through long-range LoRa communication.

⚙ Automated Control

The system controls water valves and the main pump according to system conditions.

📊 Remote Dashboard

The dashboard provides real-time monitoring and control through MQTT communication.
